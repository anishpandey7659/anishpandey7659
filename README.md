## 🚀 Featured Projects

### 📚 [ArXiv Copilot](https://github.com/anishpandey7659/Arxiv-Copilot) — Agentic Research Assistant

An end-to-end RAG-based agentic research assistant that automatically fetches, processes, indexes, and answers questions over ArXiv research papers.

**Tech:** `Python` `FastAPI` `OpenSearch` `LiteLLM` `Docling` `Langfuse` `Logfire`

- Agentic RAG pipeline for searching, fetching, summarizing, and answering questions from ArXiv papers
- Automated ingestion pipeline using Docling for PDF parsing, section-based chunking, embeddings, and indexing
- Hybrid retrieval combining BM25 and vector search for better relevance
- Multi-layer AI guardrails: rate limiting, regex filtering, and LLM-based safety checks
- Provider-agnostic LLM routing via LiteLLM
- Tracing, observability, latency monitoring, and token usage tracking with Langfuse and Logfire
- Parallel paper downloading and indexing for faster ingestion

---

### 💼 [JobPilot AI](https://github.com/anishpandey7659/JobPilot) — JobMatch Agent

An AI-powered job search agent that finds, ranks, and refines job listings and tailors resumes for selected roles.

**Tech:** `Python` `LangGraph` `Langfuse`

- Multi-node LangGraph workflow covering job fetching, ranking, query reformulation, resume tailoring, and validation
- Automatic query reformulation loop that re-runs the search when ranked results are weak
- Conditional entry router supporting both job search and resume tailoring modes in a single graph
- Validation step that checks tailored resume output before returning results
- End-to-end tracing and observability across graph nodes and LLM calls with Langfuse
